
# RETAIL SALES ANALYSIS :

Retail Sales Analysis project focuses on analyzing sales data to identify customer trends, product performance, and business growth opportunities using Excel, SQL, Python, and Power BI.
The project helps improve decision-making by creating interactive dashboards, sales reports, and data-driven insights for better retail performance.

# PROBLEM STATEMENT :

In a competitive retail market, businesses need to track sales performance,
understand customer behavior, and identify growth opportunities. This project aims to
build an end-to-end analytics solution that enables insights generation from raw
transactional data using a multi-tool approach.

# BUSSINESS USE CASE : 

1. Analyze sales performance across different stores and staff
2. Identify high-value customers and buying behavior patterns
3. Perform customer segmentation for targeted marketing
4. Monitor inventory levels and product performance
5. Create an interactive Power BI dashboard for management insights

# EXCELL DATA CLENING AND PREPARATION :

1. Standardize Column Headers
o Ensure all columns across sheets (like customers, orders, products) are
consistently named (e.g., use snake_case or camelCase).
2. Remove Duplicates
o Identify and remove any duplicate records (e.g., in customers or
order_items).
3. Handle Missing Values
o Use filtering and formulas to find blanks/nulls.
o Fill missing ZIP codes or phone numbers with placeholders or “NA”.
4. Data Type Conversion
o Convert order dates, shipped dates, and required dates into Excel Date
format.
o Ensure numeric fields (quantity, price) are set to number format.
5. Data Validation
o Use dropdowns for fields like order_status (Pending, Shipped, Delivered)
to ensure consistency.
6. Create New Derived Columns
o Add a column in order_items to calculate total_price = (list_price *
quantity) - discount.
7. Merge Lookup Data
o Use VLOOKUP or XLOOKUP to merge product names into order_items
using product_id.
8. Create Basic Pivot Table
o Build a pivot table summarizing total sales by product category.
9. Sort and Filter for Outliers
o Find outliers in pricing (e.g., products with very high or low list_price).
10. Prepare Final CSVs
o Save cleaned sheets as CSVs named: customers.csv, orders.csv, etc.,
for SQL import.
